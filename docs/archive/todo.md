# 失能患者视线检测交互应用开发计划

> 历史归档说明（2026-04-26）：本文是项目最早期的任务草案，绝大部分条目已经被后续实现和文档替代，不再作为当前待办来源。当前待办请查看根目录 `todo.md`。

## 项目目标
为失能患者创建一款移动视线检测应用，通过2-3台设备阵列实现简单信息传递，重点是判断患者是否"正在注视这部手机"

## 设备环境
- 测试设备：2台华为手机，1部iPhone
- 开发环境：Windows + Cursor + Android SDK + Android Studio
- 目标：优先在华为设备上测试
