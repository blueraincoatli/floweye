# 研究计划：移动端视线检测技术与实现路径

## 目标
1.  调研2024-2025年移动端视线检测技术的最新发展。
2.  分析MediaPipe Face Landmarker V5的最新版本及其在华为设备上的兼容性。
3.  研究华为鸿蒙系统对Android应用的支持情况。
4.  调研移动端视线检测的开源替代方案。
5.  整合现有技术方案，提出最优的MVP实现路径。

## 研究细分
1.  **技术趋势研究**
    *   1.1 调研2024-2025年移动端视线检测技术的前沿发展，包括新的算法、模型和应用场景。
    *   1.2 关注轻量级模型和设备端（On-Device）AI的最新进展。
2.  **MediaPipe方案分析**
    *   2.1 获取MediaPipe Face Landmarker V5的最新版本信息，包括性能提升、API变更等。
    *   2.2 测试或调研其在无GMS的华为设备上的兼容性和性能表现。
3.  **华为生态系统研究**
    *   3.1 调研华为HMS Core中是否包含可替代GMS视觉服务的API，特别是与相机和机器学习相关的服务。
    *   3.2 深入了解鸿蒙系统对Android应用的具体支持策略和限制。
4.  **替代方案探索**
    *   4.1 搜索并评估除MediaPipe之外的开源视线检测SDK或模型。
    *   4.2 调研WebRTC在多设备协同通信中的可行性，作为MQTT的替代或补充方案。
    *   4.3 分析Flutter、React Native等跨平台框架在集成视线检测功能方面的优缺点。
5.  **方案整合与建议**
    *   5.1 基于研究结果，对比不同技术方案的优劣。
    *   5.2 提出针对华为设备的最优技术方案。
    *   5.3 设计MVP的技术栈、架构和开发路线图。
    *   5.4 识别潜在的技术风险并制定应对策略。

## 关键问题
1.  相比现有方案，MediaPipe的最新版本在性能和功能上有哪些具体改进？
2.  在最新的华为设备和鸿蒙系统上，直接使用Android版本的MediaPipe会遇到哪些兼容性问题？
3.  华为HMS Core是否提供了比GMS更适合或性能更好的视觉处理API？
4.  除了MQTT，WebRTC是否是更优的多设备协同通信方案？其实时性和稳定性如何？
5.  目前有哪些成熟的、轻量级的开源视线检测模型可以在移动端流畅运行？
6.  采用跨平台方案（如Flutter）相比原生Android开发，对视线检测的性能和开发效率有何影响？
