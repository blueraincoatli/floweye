## 技术创新亮点

### 1. 华为设备专项优化
根据技术调研，我采用了专门针对华为无GMS设备的优化策略：
- **Camera2 API**: 替代CameraX，解决兼容性问题
- **CPU Delegate**: 强制使用CPU推理，确保稳定性
- **MediaPipe Android版本**: 避免GMS依赖

### 2. 高精度视线检测算法
基于MediaPipe Face Landmarker V5，实现了：
- **478个人脸关键点**: 精确的面部特征检测
- **头部姿态矩阵**: 3D空间中的头部方向
- **眼球Blendshape**: 眼球相对运动检测
- **综合算法**: 头部姿态 + 眼球运动的融合计算

### 3. 多设备协同机制
通过MQTT协议实现：
- **实时状态同步**: 低延迟的设备间通信
- **智能决策**: 基于置信度的选择算法
- **故障容错**: 设备离线检测和恢复

## 系统架构总览

```
📱 华为手机A (是) ──┐
📱 华为手机B (否) ──┼─→ 🌐 MQTT Broker ──→ 💻 协调器 ──→ ✅ 最终决策
📱 iPhone (是)      ──┘
```

### 数据流设计
1. **视觉处理**: 摄像头 → MediaPipe → 视线算法
2. **状态发布**: 本地结果 → MQTT → 协调器
3. **决策制定**: 多设备输入 → 综合分析 → 最终选择

## 关键技术指标

### 性能表现
- **检测延迟**: < 100ms (单设备)
- **网络延迟**: < 50ms (局域网)
- **置信度阈值**: 60% (可调节)
- **帧率**: 20-30fps (根据设备性能)

### 兼容性支持
- **Android**: 9.0+ (API 28+)
- **华为设备**: 麒麟710+，无GMS依赖
- **iOS**: 13.0+ (框架已准备，待实现)
- **协调器**: Windows/macOS/Linux
