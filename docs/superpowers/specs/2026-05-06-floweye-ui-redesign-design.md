# Floweye UI 重设计：光圈引导系统

日期：2026-05-06
状态：Design Approved

## 1. 设计目标

重设计 Android 端界面，使其：
- 对失能患者：降低认知负担，用视觉引导帮助视线聚焦
- 对操作者（家属/护工）：方便校准和设备管理
- 支持多主题切换，适应不同患者偏好

## 2. 核心视觉概念

**屏幕是灯，注视让它亮起来。**

每台设备屏幕是一个"信号灯"。未注视时安静暗淡；注视时，光圈从屏幕边缘向中心文字汇聚，越注视越亮越集中。

三个视觉层次：
1. **氛围层**（背景）：微弱的色彩呼吸，表达设备存活
2. **引导层**（光圈）：注视时从大→小收缩的发光圆环，引导视线到中心
3. **焦点层**（文字+进度）：中心大字 + 环绕圆弧进度

## 3. 视觉反馈两段式设计

解决视线游移导致的闪烁问题：

| 阶段 | 时间 | 视觉表现 |
|------|------|---------|
| 感知阶段 | 0 - 0.5s | 仅背景/光圈微微变亮（alpha 0.3 -> 0.5），不启动收缩 |
| 引导阶段 | > 0.5s | 光圈从大向小收缩，进度条开始填充 |
| 视线离开 | - | 光圈不立即消失，缓慢扩散回初始位（0.8s 过渡） |

## 4. 主题系统

三套主题，通过设置切换，只替换颜色和动效参数：

| 参数 | 温暖疗愈 | 高对比功能 | 现代简约 |
|------|---------|-----------|---------|
| 背景 | 深暖灰 `#1C1917` | 纯黑 `#000000` | 浅灰白 `#F5F5F0` |
| 光圈色（是） | 柔和翠绿 `#6BA87A` | 鲜明绿 `#00FF66` | 靛蓝 `#4A7FD9` |
| 光圈色（否） | 暖珊瑚 `#C47A6E` | 鲜明红 `#FF3333` | 灰蓝 `#7A8B9E` |
| 文字 | 暖白 `#F5F0E8` | 纯白 `#FFFFFF` | 深灰 `#1A1A1A` |
| 光圈模糊度 | 高（柔和） | 低（锐利） | 中等 |
| 脉动周期 | 慢 2.5s | 中 1.5s | 中 2.0s |

## 5. 各状态视觉设计

### 5.1 IDLE（待机）
- 背景：主题背景色，极缓慢亮度呼吸（0.95 -> 1.0 alpha，3s 周期）
- 中央：小号"你好"文字，低对比度
- 光圈：隐藏
- 边缘：顶部左上角一个 8dp 圆点显示连接状态（绿/黄/红）

### 5.2 TRANSITION（过渡）
- 背景快速平滑过渡到下一状态颜色
- 文字淡出，光圈隐藏

### 5.3 SCAN（扫描选择）
**播报阶段（announce）**：
- 选项名在中央大字显示（如"不舒服"），2s 后淡出

**选择阶段（scan_progress）**：
- 中央大字"是"或"否"
- 光圈出现：从约屏幕 80% 宽度半径，慢速收缩到文字周围（约 30% 宽度）
- 注视时光圈持续收缩 + 亮度增强；未注视时光圈缓慢扩散变暗
- 圆弧进度条围绕文字，在光圈内侧，从 0 度顺时针填充到 360 度
- 进度完成时光圈脉冲（快速扩大->缩小），给予确认反馈

### 5.4 CONFIRM（确认）
- 与 SCAN 类似，但背景色切换为确认主题色
- 光圈颜色更饱和
- 文字变为"确认: [选项名]"

### 5.5 FEEDBACK（反馈）
- 光圈快速扩散消失
- 中央显示"已通知\n[选项名]"，带对勾图标
- 1.5s 后淡出回到 IDLE

### 5.6 EMERGENCY（紧急）
- **患者屏幕上与普通选项一致**，不做特殊视觉强调
- 紧急的"特殊性"只在协调器端和护理端体现
- 避免引起患者慌乱

## 6. 边缘状态层

替代当前的纯文字状态栏：

**顶部**：
- 左上角：连接状态小圆点（8dp，绿/黄/红）
- 右上角：设置齿轮图标（仅操作者模式可见）

**底部**：
- 一条 2dp 细线显示设备角色和深度信息，颜色跟随层级主题

**患者模式 vs 操作者模式**：
- 患者模式：隐藏所有状态文字，只保留连接圆点 + 校准按钮
- 操作者模式：点击连接圆点展开详细信息面板（摄像头/MQTT/置信度）
- 校准按钮：始终可见，36dp 圆形，屏幕底部角落，交互进行中时降为半透明

## 7. 视线引导光圈（GazeHaloView）

自定义 View，Canvas + RadialGradient 绘制：

- 外圈光晕：半透明圆环，从 radius*0.8 到 radius，带模糊边缘
- 内圈焦点：围绕文字的细线圆环，跟随进度填充弧度
- 注视时：外圈 radius 随时间缩小，alpha 增加
- 未注视时：外圈 radius 缓慢扩大，alpha 降低
- 属性动画驱动 radius 和 alpha，平滑过渡

### 光圈参数

```
初始半径: screenWidth * 0.4
目标半径: screenWidth * 0.15
收缩时长: 与注视阈值一致（1.5s）
扩散时长: 0.8s
光晕宽度: radius * 0.2
模糊半径: theme-dependent (温暖=16dp, 高对比=4dp, 简约=8dp)
```

### 圆弧进度条

- 位于光圈内侧，半径 = 光圈半径 * 0.85
- 线宽 4dp
- 从 12 点方向顺时针填充
- 颜色与光圈一致但更饱和

## 8. 字体与排版

- 主按钮文字：系统默认无衬线粗体，96-160sp 自适应
- 选项名文字：48sp，中等粗细
- 状态文字：12sp，低对比度

## 9. 音效配合

- 光圈开始收缩（进入引导阶段）：低频嗡声渐入
- 选择确认：清脆叮声
- 跳过：柔和嗖声
